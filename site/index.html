NEW / REVIEWED COMPUTER ACTIONS

A second pair of hands.
You approve the next move.

Computer mode runs in the Windows download. This page is a guide and cannot inspect or control your computer.

01 / CHOOSEPick the app.

Enable a ten-minute control session. Open Notepad, Calculator or Paint, or select an existing supported window. Inspect its accessible controls locally.

→
02 / DIRECTTell Jarvis what to do.

Choose Astra or Fable and effort. Allow a fresh reading of the selected window’s accessible text, including editable values, to reach your subscription model. No desktop image or audio is captured by this mode.

03 / REVIEWApprove one action.

Review the target, text replacement or shortcut. Approve executes one operation; Reject executes nothing. Plan the next step to inspect the result. Each step uses allowance; Fable can consume paid usage credits.

→
04 / STOPKeep control.

Stop in Jarvis, uncheck permission, or press Ctrl+Shift+F12. Approvals expire after one minute and sessions after ten minutes, with up to 20 model steps. Stop does not undo a completed action.

Accessible controls only. No canvas drawing, coordinate clicking, Explorer control, terminal or address-bar control, arbitrary shell tool, or administrator prompts. Not every app exposes usable controls. Every approval deserves a review: a click or key can send, delete, purchase, or trigger behavior in the target app. Read the Computer mode guide ↗

  1. Download and run Jarvis

    Open the downloaded Jarvis-0.8.0-Windows-x64.exe. It sets itself up in your user folder and opens the companion. No administrator access needed.

  2. Talk through the next task

    Press Ctrl+Shift+Space whenever you want to bring the companion forward. Use typed direction, optional local dictation, or an explicit current-window screenshot. The exact captured frame stays visible for review.

  3. Choose your model and workflow

    Select Astra or Fable 5.1, then low through max effort. Use Setup to sign in with ChatGPT or Claude, then choose the builder or Computer mode workflow. Computer actions still require separate consent and one approval each.

  4. Open it again anytime

    Use the Jarvis shortcut on your Desktop or Start menu. The tray icon lets you reopen the companion or choose Quit Jarvis.

03 / YOU STAY IN CONTROL

Clear boundaries.
Useful output.

What does this website collect?

The walkthrough runs in your browser. Vercel processes standard hosting request data and collects cookieless page-view analytics. This site does not ask for your provider password or tokens.

What leaves my computer when I build?

The local workbench sends your prompt, any included reference frame, and relevant previous application source through Codex to OpenAI or Claude Code to Anthropic, according to your model choice. Camera sharing is explicit. Live build has separate consent for automatic screen snapshots, with the exact sent frame available for review. No audio or full video stream is sent. Credentials stay with the local CLI. Fable can use paid Claude usage credits.

Can I generate here without installing anything?

No. This website provides a prepared walkthrough. Real generation requires the local workbench and eligible subscription access. An account alone does not guarantee access to the model Jarvis needs.

What if setup or generation fails?

Use Check again in Setup after signing in. Jarvis shows missing model access and subscription limits without switching billing routes. Fable shows a live draft as HTML arrives, with scripts disabled until completion. Astra’s current CLI releases completed messages. Use low effort for smaller, faster changes, and switch back to the last working version while waiting. Fable drafts update during generation; the fully interactive version opens after completion. Saved versions and source remain available when generation or preview fails.

Can I use voice, a camera, or an image instead?

Yes. Use Connect camera and choose a camera, upload a JPEG, PNG, or WebP reference, or build from typed directions alone. Windows local dictation turns microphone input into editable text before you choose to build. Optional spoken replies use an available local browser voice. Camera and dictation permissions are explicit; desktop audio is not part of screen sharing.

What can I do with a finished prototype?

Interact with it in Desktop, Mobile, or expanded preview. Inspect Source, download the single HTML file, or restore one of up to 12 saved versions with its reference image. **Settings → Import a saved HTML prototype** imports an exported HTML file up to 120,000 bytes and adds a revision when the desktop profile has room. New project asks before clearing saved work. Source-development browser profiles and older browser-based installs are separate. Runtime data inside a prototype resets when reopened. Retry preview reopens saved source without another model request.

Can it build a backend or control my desktop?

The prototype builder creates frontend web pages. Separately enabled Computer mode can inspect and operate accessible Windows controls, with your approval before each action. It has no canvas drawing, generic shell tool, elevated access, repository-editing tool or backend/deployment integration. Explorer, terminals, address controls and protected windows are excluded. The in-app preview blocks external network access, nested frames, and camera or microphone access. Exported HTML runs outside that boundary.

Can I try anything before signing in?

The downloaded app includes a working sample you can explore without a model call or login. Generating your own result requires eligible subscription access. Setup offers installation, sign-in, Check again, and cancellation. Start new allowance resets Jarvis's local counter only; it does not renew your provider allowance. Missing access and usage limits stop generation without switching models or billing routes.

Does this work on Mac or Linux?

The one-click launcher is for Windows. The source includes a Node.js server, but this download flow does not include a Mac or Linux launcher.
