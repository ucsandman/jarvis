  1. Download and run Jarvis

    Open the downloaded Jarvis-0.3.0-Windows-x64.exe. It sets itself up in your user folder and opens the workbench. No administrator access needed.

  2. Sign in with ChatGPT

    Open Setup and choose Sign in with ChatGPT. Complete OpenAI's browser sign-in. Node.js and the official Codex CLI are already included.

  3. Choose a reference and describe the result

    Select an image or camera frame, describe what to build, and approve sharing that frame. Keep iterating, restore a version, or download the HTML.

  4. Open it again anytime

    Use the Jarvis shortcut on your Desktop or Start menu. The tray icon lets you reopen the workbench or choose Quit Jarvis.

03 / YOU STAY IN CONTROL

Clear boundaries.
Useful output.

What does this website collect?

The walkthrough and sample run in your browser. No text from the sample is sent to Jarvis. Vercel processes standard hosting request data and collects cookieless page-view analytics. This site does not ask for your ChatGPT password or tokens.

What leaves my computer when I build?

The local workbench sends your prompt, any included reference frame, and relevant previous application source through the official Codex CLI to OpenAI. Camera sharing is explicit. Your ChatGPT credentials stay with the local CLI.

Can I generate here without installing anything?

No. This website provides a prepared walkthrough and static sample. Real generation requires the local workbench and eligible subscription access. A ChatGPT account alone does not guarantee access to the model Jarvis needs.

What if setup or generation fails?

Use Check again in Setup after signing in. Jarvis shows missing model access and subscription limits without switching billing routes. Saved versions and source remain available when generation or preview fails.

Does this work on Mac or Linux?

The one-click launcher is for Windows. The source includes a Node.js server, but this download flow does not include a Mac or Linux launcher.
