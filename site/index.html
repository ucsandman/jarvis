  1. Download and run Jarvis

    Open the downloaded Jarvis-0.6.0-Windows-x64.exe. It sets itself up in your user folder and opens the workbench. No administrator access needed.

  2. Choose your model and sign in

    Select Astra or Fable 5.1, then low through max effort. Use Setup to sign in with ChatGPT or Claude. Node.js and Codex are included; the Claude Code install button downloads its verified runtime directly from Anthropic.

  3. Share your design window

    Choose Share screen or window, describe the product, then approve Live build. Jarvis sends changed snapshots after you pause drawing. Builds are at least 30 seconds apart by default, with up to 10 per start. Pause or stop sharing anytime. Camera and uploads are still available.

  4. Open it again anytime

    Use the Jarvis shortcut on your Desktop or Start menu. The tray icon lets you reopen the workbench or choose Quit Jarvis.

03 / YOU STAY IN CONTROL

Clear boundaries.
Useful output.

What does this website collect?

The walkthrough runs in your browser. Vercel processes standard hosting request data and collects cookieless page-view analytics. This site does not ask for your provider password or tokens.

What leaves my computer when I build?

The local workbench sends your prompt, any included reference frame, and relevant previous application source through Codex to OpenAI or Claude Code to Anthropic, according to your model choice. Camera sharing is explicit. Live build has separate consent for automatic screen snapshots, with the exact sent frame available for review. No audio or full video stream is sent. Credentials stay with the local CLI. Fable can use paid Claude usage credits.

Can I generate here without installing anything?

No. This website provides a prepared walkthrough. Real generation requires the local workbench and eligible subscription access. An account alone does not guarantee access to the model Jarvis needs.

What if setup or generation fails?

Use Check again in Setup after signing in. Jarvis shows missing model access and subscription limits without switching billing routes. Fable shows a live draft as HTML arrives, with scripts disabled until completion. Astra’s current CLI releases completed messages. Use low effort for smaller, faster changes, and switch back to the last working version while waiting. Fable drafts update during generation; the fully interactive version opens after completion. Saved versions and source remain available when generation or preview fails.

Can I use voice, a camera, or an image instead?

Yes. Use Connect camera and choose a camera, upload a JPEG, PNG, or WebP reference, or build from typed directions alone. Windows local dictation turns microphone input into editable text before you choose to build. Optional spoken replies use an available local browser voice. Camera and dictation permissions are explicit; desktop audio is not part of screen sharing.

What can I do with a finished prototype?

Interact with it in Desktop, Mobile, or expanded preview. Inspect Source, download the single HTML file, or restore one of up to 12 saved versions with its reference image. New project asks before clearing this browser's history. Versions stay in the same browser profile and local address; they are not cloud-synced. Runtime data inside a prototype resets when reopened. Retry preview reopens saved source without another model request.

Can it build a backend or control my desktop?

Jarvis builds frontend web prototypes. Screen sharing supplies visual context; Jarvis does not click around your desktop, edit your repositories, deploy services, or connect a real backend. The in-app preview blocks external network access, nested frames, and camera or microphone access. Exported HTML runs outside that boundary.

Can I try anything before signing in?

The downloaded app includes a working sample you can explore without a model call or login. Generating your own result requires eligible subscription access. Setup offers installation, sign-in, Check again, and cancellation. Start new allowance resets Jarvis's local counter only; it does not renew your provider allowance. Missing access and usage limits stop generation without switching models or billing routes.

Does this work on Mac or Linux?

The one-click launcher is for Windows. The source includes a Node.js server, but this download flow does not include a Mac or Linux launcher.
