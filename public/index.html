      THE EVOLUTIONEvery build keeps the previous version.

      Your first version starts with an idea.

      YOUR DESK. YOUR CONTROL.

      What leaves this device.

      Camera preview stays local. Building shares your selected image, direction, and current prototype source with your selected provider: Astra through Codex and ChatGPT, or Fable through Claude Code and your Claude subscription. There is no continuous upload and no model API integration.

      Revisions, including their reference images, are stored in this browser on this device. Up to 12 versions are kept. “New project” clears this project’s stored history.

      Subscription login is required. When access or usage limits prevent a request, Jarvis stops. It never uses an API key or another model as a fallback. Fable can consume usage credits under your Claude account settings.

      Generated applications run in a restricted frame. They cannot access Jarvis’s camera, credentials, or saved revisions. Prototype data resets when a version is reopened.

      A request already received by the selected CLI may finish after you cancel. Jarvis discards a canceled result.
